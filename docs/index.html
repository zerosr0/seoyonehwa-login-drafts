SEOYON E-HWA QMS 로그인 페이지 시안

카드를 클릭하면 각 시안의 정적 목업이 열립니다. 배경 슬라이드와 비밀번호 보기 등 화면 동작은 실제와 같고, 로그인 버튼만 동작하지 않습니다.

시안 1

슬라이드형

좌측 로그인 카드 + 우측 사선 배경 슬라이드, 하단 슬로건
시안 2

중앙 카드형

전체 화면 배경 슬라이드(남색 오버레이) + 정중앙 카드
시안 3

다크 테마

좌측 어둡게 처리한 슬라이드 + 우측 다크 패널 폼, 오렌지 포인트

실제 ASP.NET 소스는 저장소의 WebProjects 폴더에 있습니다. 목업은 PC 해상도(1200px 이상) 기준이며, 768px 이하에서는 모바일 레이아웃으로 전환됩니다.
